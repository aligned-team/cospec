## Why

CONTRIBUTING.md documents the mechanics of the cospec workflow but never states
plainly that this repository is built with its own tool. New contributors should
learn up front that cospec dogfoods itself, so the workflow reads as a lived
practice rather than optional ceremony.

## What Changes

- Add a `## Self-hosting` section to `CONTRIBUTING.md` stating that every
  substantive change here is driven through cospec's own loop (new → author →
  validate → apply → implement → archive).

## Impact

- `CONTRIBUTING.md` only. No code, schemas, or specs affected.
