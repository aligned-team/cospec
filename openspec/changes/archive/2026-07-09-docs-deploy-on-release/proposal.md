## Why

The docs site currently deploys on every push to `main` that touches docs paths,
so it can drift ahead of or behind the released CLI it documents; docs deploys
must instead be tied to releases, PR-time docs builds need CI coverage, and this
branch's `mise run generate:check` failure (pre-existing release-stamp drift on
`main`, surfaced here because this PR touches `mise.toml`) must be cleared
before merge.

## What Changes

- `.github/workflows/docs.yml` — replace the `push` trigger with `workflow_call`
  (optional `ref` input) so the site deploys only when invoked by the release
  pipeline; keep `workflow_dispatch` as a manual escape hatch. No change to the
  build/deploy jobs themselves.
- `.github/workflows/release.yml` — add a `deploy-docs` job
  (`needs: [bump, publish]`, Pages permissions) that calls
  `./.github/workflows/docs.yml` with `ref: ${{ needs.bump.outputs.sha }}` once
  the release is published and all npm packages are live.
- `.github/workflows/ci.yml` — add a `docs` path filter to `detect-changes` and
  a `ci-docs` job (`mise run docs:build`) wired into `ci-gate`, so a broken
  VitePress build blocks merge at PR time.
- Commit the 32 managed files regenerated by `mise run generate` (`.claude/`,
  `.codex/`, `.opencode/`, `openspec/.cospec-manifest.json`) to restamp
  `generatedBy`/`cospecVersion` to `cospec@0.2.1` — this is the sanctioned fix
  for the pre-existing canon-drift gate failure, not new scope; called out
  separately in the PR description.
- No `hk.pkl` changes: existing oxfmt/oxlint globs already cover
  `apps/docs/**/*.{md,mts,ts}`; the VitePress build stays out of
  pre-commit/pre-push and lives only in `ci-docs` and the release deploy.

## Impact

- Workflows: `docs.yml`, `release.yml`, `ci.yml`.
- Jobs: new `ci-docs` (required via `ci-gate`), new `deploy-docs` in the release
  pipeline; `docs.yml`'s existing `build`/`deploy` jobs unchanged in substance.
- No secrets added; `deploy-docs` inherits `pages`/`id-token` permissions
  already used by `docs.yml`.
- Managed files: 32 files under `.claude/`, `.codex/`, `.opencode/`, plus
  `openspec/.cospec-manifest.json` (version-stamp only, generated).
